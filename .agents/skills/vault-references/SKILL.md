# Reusable references

Read `Agent System/system/vault-model.md` and `Agent System/system/ownership.md` from the vault root. Inspect existing references and relevant project/task context before creating information. Reuse an existing authoritative note when the material covers the same subject.

Use `Project Management/Templates/Reference.md` for new records. Preserve the user's findings and source links, distinguish evidence from interpretation, and make uncertainty explicit. Record known project associations and producing tasks using the shared contract. Do not infer that every project of a producing task must use the reference.

When extracting a task's findings, preserve meaningful history in the task and link the authoritative reference rather than leaving competing copies. Delegate changes to consuming tasks' reference links to `vault-tasks`; delegate execution decisions to `vault-projects`. Provenance does not mark a task complete or satisfy dependencies.

Return reference paths, known consumers or producing tasks, and unresolved information. Preserve reference notes when linked work completes or is archived. View presentation belongs to `vault-dashboard`; this skill owns reference content and metadata.
